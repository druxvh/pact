# The portrait mask

`marcus-bust.png` is a small dithered black-and-white mask made from a photograph on Wikimedia Commons (cropped, then converted to a
1-bit dither); the photograph itself is not in the repository. It is the source `scripts/stylewall/plates.ts` re-renders as the
Engraved Halo wallpaper's plate, so the credit is listed with the wallpaper's (`src/features/stylewall/credits.ts`, shown in Settings →
About → Image credits).
